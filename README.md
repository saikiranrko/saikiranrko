## Selected platform work

### Enterprise developer platform

- Govern GitHub Enterprise, JFrog Artifactory, SonarQube, Jira, and Confluence for **100+ engineering teams**.
- Administer **5,000+ repositories** and **10,000+ GitHub Teams**, with identity-based access and security policy enforcement.
- Built **20+ reusable GitHub Actions workflows** across Java, .NET, Node.js, and Python ecosystems.
- Deployed Actions Runner Controller across AKS to provide secure, containerized CI execution at enterprise scale.

### Multi-cloud Kubernetes & security

- Design and operate production platforms across **AKS, EKS, GKE, and ROSA** using Helm, Istio, autoscaling, PDBs, and NetworkPolicies.
- Create reusable Terraform modules for AWS, Azure, and GCP with remote state, drift detection, and governed delivery.
- Integrate Veracode, SonarQube, Prisma Cloud, OPA/Gatekeeper, secrets management, and zero-trust service communication.
- Built AWS hub-and-spoke networking with Transit Gateway, AWS RAM, Organizations/SCPs, VPN, PrivateLink, and private DNS.

### Production AI platform

- Delivered Kubernetes infrastructure for enterprise LLM workloads using **LangGraph, Qdrant, Vertex AI, NeMo Guardrails, and Langfuse**.
- Architected RAG ingestion and retrieval services with vector indexing, workload observability, token/cost monitoring, and prompt-injection defenses.
- Extended enterprise CI/CD governance to AI application build, test, containerization, and AKS deployment.
